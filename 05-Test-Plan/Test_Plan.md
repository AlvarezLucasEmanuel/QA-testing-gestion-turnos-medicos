---

# 2. Objetivo

El objetivo de este plan de pruebas es definir la estrategia para verificar el correcto funcionamiento del sistema de Gestión de Turnos Médicos, asegurando que los requisitos funcionales implementados cumplan con las necesidades del usuario y que las funcionalidades principales operen de forma correcta.

---

# 3. Alcance

Este plan contempla pruebas funcionales sobre los siguientes módulos:

- Login
- Gestión de Pacientes
- Gestión de Turnos

Las pruebas incluyen:

- Casos positivos.
- Casos negativos.
- Validaciones de campos.
- Reglas de negocio.
- Mensajes del sistema.

No se incluyen pruebas de rendimiento, seguridad, automatización ni pruebas de carga.

---

# 4. Estrategia de Pruebas

Se utilizarán técnicas de pruebas manuales basadas en los requisitos funcionales del sistema.

Se elaborarán:

- Casos de prueba.
- Matriz de Trazabilidad (RTM).
- Checklists.
- Reportes de Bugs.

Las pruebas serán ejecutadas de manera funcional verificando el comportamiento esperado de cada módulo.

---

- Sistema Operativo: Windows 11
- Navegador: Opera
- Tipo de prueba: Manual
- Gestión de documentación: GitHub
- Herramientas utilizadas:
  - Git
  - GitHub
  - Visual Studio Code
  - Microsoft Excel

---

# 6. Criterios de Entrada

Las pruebas podrán comenzar cuando:

- Los requisitos funcionales estén definidos.
- El sistema se encuentre disponible.
- Existan datos de prueba para ejecutar los escenarios.

---

# 7. Criterios de Salida

Las pruebas finalizarán cuando:

- Todos los casos de prueba hayan sido documentados.
- Los defectos críticos hayan sido identificados.
- Se complete la documentación del proceso de pruebas.

---

# 8. Riesgos

- Cambios en los requisitos durante las pruebas.
- Indisponibilidad del sistema.
- Datos de prueba insuficientes.
- Errores que impidan la ejecución de determinados casos.

---

# 9. Entregables

Como resultado del proceso de pruebas se generan los siguientes documentos:

- Casos de Prueba.
- Matriz de Trazabilidad (RTM).
- Checklists.
- Reportes de Bugs.
- Test Plan.
